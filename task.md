Мы делаем собственную систему аналитики (Self-hosted Analytics) для портфолио.
Стек: Python (FastAPI + SQLite) на бэкенде, React на фронтенде.
Шаг 1: Бэкенд (/backend)
Создай папку backend и файлы в ней:
database.py: Настройка SQLite + SQLAlchemy. Две модели:
Visit: id, ip, user_agent, target_company (из ?for=), timestamp, location (заглушка).
Event: id, visit_id, event_name, details, timestamp.
main.py: FastAPI приложение.
POST /api/visit: Создает новую сессию визита. Возвращает visit_id.
POST /api/event: Принимает visit_id, event_name, details. Пишет в базу.
GET /api/admin/stats: Защищенный эндпоинт (Basic Auth, логин/пароль: admin/secret). Возвращает список визитов с вложенными событиями, отсортированный по времени (новые сверху).
Настрой CORS, чтобы фронт с localhost:3001 (или другого порта) мог слать запросы.
Шаг 2: Клиентский трекер (src/utils/tracker.ts)
Напиши класс Tracker:
Метод init(): Проверяет localStorage. Если сессии нет или она старая (>4 часов) — делает запрос POST /api/visit (передает target_company из URL). Сохраняет visit_id.
Метод track(name, details): Шлет событие на бэк, если visit_id существует.
Экспортируй единственный инстанс этого класса.
Шаг 3: Интеграция в App.tsx
В useEffect при загрузке вызывай tracker.init().
Навесь события tracker.track(...) на ключевые действия:
Открытие демок (какой продукт).
Открытие терминала.
Клик по контактам.
Смена темы.
Шаг 4: Админ-панель (src/pages/AdminDashboard.tsx)
Создай новую страницу, доступную по роуту /secret-dashboard.
Авторизация: Простая форма ввода пароля (сравниваем с захардкоженным 'secret', при успехе сохраняем токен в стейт/localStorage для запросов к API).
Интерфейс:
Сверху KPI: "Всего визитов", "VIP визитов (с ?for=)", "Конверсия в контакты".
Таблица визитов: Дата, IP, Компания (выдели жирным/цветом, если есть), Устройство.
Детализация (Accordion): При клике на строку визита разворачивается список всех действий этого человека с таймстемпами (хронология).
Сделай автообновление данных каждые 10 секунд.
Добавь этот роут в main.tsx.
Сделай UI админки в темном стиле, строгим и "инженерным" (используй существующие Tailwind классы и Lucide иконки).
